# Apni Dukaan 🛒 "Apni Dukaan" ek modern aur lightweight e-commerce web application hai jise dairy store (jaise milk, paneer, ghee) ke products ke liye design kiya gaya hai. ## 🚀 Features - **Product Catalog**: Alag-alag dairy items ko dekhne aur browse karne ki suvidha. - **Cart Management**: Cart mein items add karna, quantity manage karna aur total bill calculate karna. - **Data Persistence**: LocalStorage ka use jisse page refresh hone par bhi cart ka data save rahe. - **Simulated Checkout**: UPI QR code payment aur Cash on Delivery (COD) ka option. ## 🛠️ Tech Stack - **HTML5** - **CSS3** - **JavaScript (Vanilla)** - **GitHub Pages** (Hosting) -
